Eric Nawrocki

This subdirectory contains the files backing the locked headline ZIKV
annotation benchmark: 1219 pass / 35 fail out of 1254 (97.21%).

Settled config (the documented v-annotate.pl command is in va-full1254-bothlevers.sh):
  perl v-annotate.pl --cpu 8 --split -r --keep --nosub --lowsim5ftr 15 --lowsim3ftr 15 \
    --r_file <package>/zika.rpn.fa --mkey zika --mdir <package> \
    zikv-test-2026-05-04.fa <outdir>

  This is the exact command that produced the result files below: released
  VADR 1.7.1, the published vadr-models-zika-1.7.1-2 package.

  CM: ere-1.1 (the "both levers" config = --lowsim5ftr 15 AND --lowsim3ftr 15,
  locked in as the release configuration after comparing it against
  single-lever and no-lever alternatives on this same test set).
  mdir: the published vadr-models-zika-1.7.1-2 package (see top-level README
  for where to obtain it).

  va-full1254-bothlevers.sh documents this command (with internal paths
  redacted to placeholders, same convention as elsewhere in this package).

Files:
  full1254-bothlevers.verdict.tsv   per-sequence pass/fail verdict table
  va-full1254-bothlevers.sh         documented v-annotate.pl command (see note above)
  va-full1254-bothlevers.vadr.alc   alert code summary (counts per alert type)
  va-full1254-bothlevers.vadr.alt   per-sequence/feature alert instance listing
  va-full1254-bothlevers.vadr.pass.list   1219 accessions that passed
  va-full1254-bothlevers.vadr.fail.list   35 accessions that failed
  va-full1254-bothlevers.vadr.sqa   per-sequence annotation summary
  zikv-test-2026-05-04.list         the 1254 accessions making up the test set,
                                     one per line, in the order they were run

NOTE: va-full1254-bothlevers.vadr.ftr (feature-level per-sequence detail) is
NOT included here -- it is not needed to reproduce the headline pass/fail
counts or the 35-sequence failure-mode table, and was excluded on package-size
grounds. It can be regenerated by re-running the command above.

RELEVANCE TO PAPER: the locked 1219/35/1254=97.21% headline accuracy figure,
and the residual 35-sequence failure-mode breakdown (see .vadr.alc for
alert-type counts among the 35 failures).
