MODEL-SCOPE NOTE (updated for the published package): the model is named
"zika" in the published package (was "zikv-canonical" in the pre-release
mdir-ere1.1 this panel originally used; same CM, renamed only). It classifies
to a single protein-coding model with 16 features (1 gene, 1 CDS polyprotein,
14 mat_peptides). Unlike the pre-release mdir, the published package's
zika.minfo DOES declare a subgroup (derived from zika.stk), which turns on
nearest-neighbor clade classification — every sequence now also carries a
"sub grp"/"fract id" classification and, on 882/981 sequences here, the
non-fatal INDEFINITE_CLASSIFICATION_NN (nnindfcl) alert (small margin between
best and 2nd-best clade identity). This is new relative to the original
981-seq comparison and does not affect pass/fail status anywhere below.
(NOTE, unchanged: the .ftr file for this run DOES show extra ncRNA/stem_loop
features beyond the 848-seq run's protein-only mdir — reflecting the current
model package's added structural-RNA content vs. the OLD canonical-8seq-cm
mdir used for va848 — but vadr-ftr-to-ftrsum.pl filters to CDS/mat_peptide
only for the VIGOR4 comparison, so this doesn't change the feature-comparison
scope. The published package's zika.minfo also redefines the ncRNA feature
itself, from "Flavivirus 5' UTR (Rfam 14.10)" at 1..162 to "sfRNA1" at
10395..10807 — again invisible to this CDS/mat_peptide-only comparison, but
it is why one FAILing sequence below (KX198134.2) no longer carries indf5gap:
that alert was firing on the old 5'-UTR ncRNA feature, which no longer exists
in that form.)
